# ChatTiles — сайт для GitHub Pages

Статический сайт без сборки, зависимостей, аналитики и внешних шрифтов.

## Файлы

- `index.html` — главная, возможности, иллюстрация виджета, FAQ и контакт.
- `guide/index.html` — инструкция по настройке.
- `privacy/index.html` — Privacy Policy текущей версии 0.1.0.
- `styles.css` — адаптивное оформление.
- `assets/icon.png` — согласованная иконка с AI-искрой.
- `.nojekyll` — публикация обычных статических файлов.

## Публикация

1. Создать отдельный публичный репозиторий, например `chattiles`.
2. Загрузить **содержимое этой папки** в корень ветки `main`, сохранив вложенные папки.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Дождаться успешного развёртывания Pages.
5. Проверить главную, `/guide/` и `/privacy/` по полученному адресу.

Относительные ссылки поддерживают размещение в подпапке репозитория. Своего домена не требуется. Никакие исходники Android-приложения или ключи подписи сюда не включены.

## Локальный просмотр

В этой папке выполнить `python3 -m http.server 8000`, затем открыть `http://localhost:8000/`.
